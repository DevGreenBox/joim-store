# JOIM STORE

Интернет-магазин бренда JOIM: два пусковых устройства Easy Start и
портативный автопылесос. Каталог с фильтрами, карточка товара с галереей
и 360°-облётом, корзина, оформление заказа, смежные страницы.

Next.js 16 (App Router, Turbopack) + React 19 + TypeScript + Tailwind CSS 4.

> Товары настоящие: характеристики, цены, фотографии и отзывы взяты
> из материалов бренда и с площадок, где он продаёт. Телефон, адрес, почта,
> часы работы и реквизиты — демонстрационные. Заказ уходит продавцу
> в Telegram, оплата на сайте не подключена.
> Что заменить перед запуском — в конце [docs/brief.md](docs/brief.md)
> и в [.env.example](.env.example).
>
> Сайт самостоятельный: продаёт со своей витрины, ни с какими маркетплейсами
> не связан и наружу ничего не отправляет.

## Страницы

| Маршрут | Что это |
| --- | --- |
| `/` | Витрина: герой, линейка, преимущества, подбор модели, категории, FAQ |
| `/catalog` | Каталог: фильтры по категории и цене, сортировка, поиск |
| `/catalog/[category]` | Страница категории: показания, модели, выход в подбор |
| `/product/[slug]` | Мини-лендинг модели: галерея, показания, комплект, 360°, сценарии, защита, экономика, отзывы, сравнение |
| `/cart`, `/checkout` | Корзина и оформление заказа |
| `/reviews` | Отзывы покупателей с распределением оценок |
| `/warranty`, `/delivery`, `/corporate` | Гарантия и возврат, доставка и оплата, корпоративным клиентам |
| `/about`, `/contacts` | О бренде, контакты |
| `/privacy`, `/offer` | Обработка персональных данных, условия продажи |

## Запуск

```bash
pnpm install
pnpm dev      # http://localhost:3000
pnpm build    # продакшен-сборка
pnpm lint
```

## Как всё устроено

- **Данные** — `content/catalog/` (товары, категории, отзывы) и
  `content/pages/` (тексты страниц, контакты). В компонентах ничего
  не захардкожено, включая заголовки секций.
- **Доступ к данным** — `lib/catalog.ts`: выборки, фильтрация, сортировка.
- **Корзина** — `lib/cart.tsx`: хранилище поверх `localStorage` через
  `useSyncExternalStore`, синхронизируется между вкладками.
- **Приём заказа** — server action `lib/actions.ts`: валидация, свой расчёт
  суммы по артикулам, уведомление продавцу в Telegram (`lib/notify.ts`)
  и накладная на печать. Доставка считается через СДЭК (`lib/cdek.ts`),
  без ключей — фиксированный тариф. Ключи — в `.env.example`.
  Оплата и хранение заказов подключаются на боевом запуске.
- **Медиа** — оригиналы в `assets/`, готовое в `public/`. Между ними
  `scripts/prepare-product-images.mjs` (sharp) и `scripts/prepare-360.mjs`
  (ffmpeg): 12,7 МБ облёта → 639 КБ с покадровой перемоткой. Промо-ролики
  готовит `scripts/prepare-videos.mjs`: 44–49 МБ → 3,2–7,1 МБ.
- **Дизайн-система** — токены, кривые движения и утилиты в `app/globals.css`.
  Типографика — Geist и Geist Mono, акцент один: `#8cc53f`.
- **Движение** — только `transform` и `opacity`, один общий
  `IntersectionObserver` в `components/ui/Reveal.tsx`. Всё, что считается
  при скролле, пишется прямо в узел мимо состояния React. Полное отключение
  при `prefers-reduced-motion`. Анимационных библиотек нет.

## Важно про версию Next

Next 16 отличается от того, что «помнят» модели: `priority` у `next/image`
объявлен устаревшим, `params` асинхронные, `next lint` удалён. Перед
написанием кода — читать гайд в `node_modules/next/dist/docs/`.
