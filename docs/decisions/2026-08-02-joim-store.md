# 2026-08-02 — Сайт JOIM STORE: стек, дизайн, анимации

## Что решили

Магазин автоэлектроники **JOIM STORE** собран в этом проекте целиком:
главная, каталог с фильтрами, карточка товара, корзина, оформление заказа,
установка, доставка, о компании, контакты.

## Дизайн

Тёмный премиум и строгий минимализм: почти монохромная палитра плюс один
тёплый акцент `#e8b563` — цвет подсветки приборной панели. Акцент работает
точечно (надзаголовки, активные состояния, статус наличия, фокус), основная
кнопка — костяной белый на почти чёрном. Токены — в `app/globals.css`
(`@theme`), там же единые кривые движения.

Шрифты: **Manrope** для заголовков, **Inter** для текста — оба с кириллицей,
через `next/font` (самохостинг, без запросов к Google).

## Анимации

Требование: элегантно, быстро, работает везде. Отсюда правила:

- Анимируются только `transform` и `opacity` — без реflow во время движения.
- Появление блоков — **один общий `IntersectionObserver`** на документ
  (`components/ui/Reveal.tsx`), элемент отписывается сразу после показа.
  Слушателей `scroll` для анимаций нет.
- Начальное скрытие включает атрибут `data-js`, который ставит инлайн-скрипт
  в `app/layout.tsx` до первой отрисовки. Без JS контент виден сразу.
  Именно атрибут, а не класс: `className` на `<html>` рисует React.
- `prefers-reduced-motion: reduce` выключает всё движение одним блоком в CSS.
- Никаких анимационных библиотек: framer-motion и подобные весят больше, чем
  весь остальной JS страницы.

## Данные и контент

Каталог — 6 категорий и 18 товаров в `content/catalog/`, тексты страниц —
в `content/pages/`. Всё вымышлено для демонстрации (см. `docs/brief.md`).

Фотографий товаров нет, поэтому `components/ui/ProductArt.tsx` рисует
инлайновые SVG-иллюстрации по категориям: ноль запросов, резкость на любом
экране. `ProductImage` показывает фото из `product.images`, как только оно
появится, — вёрстку менять не придётся.

## Корзина и заказ

Корзина — внешнее хранилище поверх `localStorage` (`lib/cart.tsx`,
`useSyncExternalStore`): на сервере снимок пустой, на клиенте — реальный,
поэтому нет расхождений при гидратации и нет `setState` в эффектах.

Заказ принимает server action `lib/actions.ts`: валидация на сервере, выдача
номера заказа. **Ничего не сохраняется и не оплачивается** — CRM и платёжный
шлюз подключаются на боевом запуске.

## Состояние каталога — в URL

Фильтры, сортировка и поиск — обычные ссылки и `next/form`, состояние живёт
в `searchParams`. Работает без JS, индексируется, подборкой можно поделиться
ссылкой. Из-за чтения `searchParams` `/catalog` рендерится по запросу,
остальные страницы — статические.

## Мелочи, которые стоили времени

- Панель мобильного меню вынесена **наружу** из `<header>`: `backdrop-filter`
  на шапке создаёт содержащий блок, и `position: fixed` внутри неё
  схлопывался до высоты шапки.
- `turbopack.root` в `next.config.ts` указан явно — рядом лежит внешний
  `pnpm-workspace.yaml`, и Turbopack иначе выбирает родительскую папку.
