# Карта проекта

Правило в одну строку: **`public/` — то, что отдаётся браузеру. `assets/` — исходники. `inbox/` — «свалка» входящих материалов, откуда всё разбирается.**

```
auto-electronics/
├── app/                    маршруты Next 16 (App Router): page.tsx, layout.tsx, route.ts
├── components/
│   ├── ui/                 мелкие переиспользуемые элементы (кнопка, поле, карточка)
│   └── sections/           крупные блоки страниц (герой, каталог, форма заявки)
├── lib/                    утилиты, работа с данными, типы
├── content/
│   ├── catalog/            данные каталога (json/md): товары, категории, характеристики
│   └── pages/              тексты статических страниц (о компании, доставка, контакты)
│
├── public/                 ⇢ раздаётся по URL от корня: public/images/hero/a.jpg → /images/hero/a.jpg
│   ├── images/
│   │   ├── products/       фото товаров (готовые, обрезанные, сжатые)
│   │   ├── brands/         логотипы производителей
│   │   ├── hero/           баннеры и обложки блоков
│   │   ├── icons/          иконки, favicon-исходники
│   │   └── og/             превью для соцсетей (1200×630)
│   ├── video/              готовое видео (mp4/webm) + постеры
│   ├── files/              PDF: прайсы, инструкции, сертификаты
│   └── fonts/              локальные шрифты (если не Google Fonts)
│
├── assets/                 ⇢ НЕ раздаётся, в бандл не попадает — только исходники
│   ├── images-raw/         оригиналы фото до обработки
│   ├── video-raw/          сырое видео до монтажа/сжатия
│   ├── brand/              логотипы в векторе, фирменный стиль, палитра
│   └── design/             макеты, скриншоты референсов
│
├── inbox/                  сюда кидаются любые входящие материалы «как есть»
├── scripts/                подготовка ассетов
│   ├── prepare-product-images.mjs   фото товаров: обрезка полей, webp
│   └── prepare-360.mjs              360°-облёт: кроп, сжатие, постер (нужен ffmpeg)
├── docs/
│   ├── brief.md            что за проект, для кого, что должно быть на сайте
│   ├── structure.md        этот файл
│   ├── content-guide.md    правила именования и подготовки файлов
│   ├── state.md            состояние проекта: сделано, не сделано, чем продолжать
│   ├── checklist.md        проверка по чек-листу качества заказчика
│   └── decisions/          решения по ходу проекта (по одному .md на решение)
└── .claude/
    ├── agents/             специализированные агенты проекта
    └── settings.json       разрешения и MCP
```

## Куда что класть

| Что появилось | Куда |
| --- | --- |
| Прислали архив фоток/видео/прайс | `inbox/` — потом разберём |
| Оригинал фото с камеры | `assets/images-raw/` |
| Обработанное фото товара для сайта | `public/images/products/` |
| Логотип поставщика | `public/images/brands/` |
| Смонтированное видео для страницы | `public/video/` |
| Исходник монтажа | `assets/video-raw/` |
| PDF-инструкция к устройству | `public/files/` |
| Описания и характеристики товаров | `content/catalog/` |
| Текст страницы «О компании» | `content/pages/` |
| Договорились о чём-то важном | `docs/decisions/` |

## Маршруты

Страницы задаются папками в `app/`: `app/catalog/page.tsx` → `/catalog`,
`app/catalog/[slug]/page.tsx` → `/catalog/<товар>`.
Файлы, которые не должны становиться маршрутом, кладутся в `_папку` с подчёркиванием.

Перед написанием кода — читать `node_modules/next/dist/docs/` (см. `AGENTS.md`):
версия Next 16 отличается от того, что «помнят» модели.
