# Panton Demo — что с ним стало

Файлы прислал заказчик 17.08.2026 вместе с формулировкой лицензии:

> You may use the free fonts as web-fonts with @font-face declaration
> to create web sites, web templates, etc.

Лицензия позволяет ставить демо на сайт. **Мы этого не делаем** —
по другой причине.

## Почему демо не встал в заголовки

**Строчных букв в начертании нет.** И кириллица, и латиница нарисованы
только прописными: коды строчных в шрифте есть, но за ними стоят те же
заглавные контуры. Заголовки шли сплошной капителью, а «JOIM Easy Start
ES-19» превращалось в «JOIM EASY START ES-19».

Для коротких баннеров это годится, для сайта с длинными заголовками
и названиями моделей — нет.

## Зачем файлы остались

Они эталон. По ним снят скелет настоящего Panton, и по этим числам
подбиралась замена:

| Величина | Panton |
| --- | --- |
| cap-height | 710 |
| x-height | 520 |
| x/cap | 0,73 |
| ширина «O» к высоте | 0,80 (Bold, интерполяция Light↔Black) |
| ширина «H» к высоте | 0,79 |
| апрош «H» / «O» / «n» | 700 / 688 / 709 |

Разбор и выбор замены — в `docs/decisions/2026-08-17-shrift.md`.

Придёт полная коммерческая версия Panton Bold — меняется одна строка
в `app/layout.tsx`, остальное подхватится: заголовки везде ходят через
токен `--font-display`.
